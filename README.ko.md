# ai-org-chart · AI 미니회사 조직도 만들기

[English](README.md) | **한국어** | [日本語](README.ja.md) | [简体中文](README.zh-CN.md)

AI 창이 열 개를 넘어가면 누가 뭘 하는지 흐려지고, 결국 내가 팀장 노릇을 하느라 일이 멈춰요.
창을 **회사처럼** 나누면 각 창은 자기 일만 하고, 나는 OK만 누르면 돼요.

### 설치 없이 바로 해 보기
자주 쓰는 AI(클로드·챗GPT·제미나이)에 [PROMPT.ko.md](PROMPT.ko.md)의 문장을 붙여 넣으세요. AI가 하나씩 물어보고 조직도까지 그려 줘요.

### 클로드 코드 스킬로 쓰기
클로드에게 이렇게 말하세요.
> "github.com/gonipro/ai-org-chart 의 skills/ai-org-chart 를 내 스킬(~/.claude/skills)에 설치하고, 내 AI 조직도를 만들어 줘"

### 만드는 순서 (요약)
1. 매주 반복되는 일을 다 적기
2. 나누는 기준 고르기: 브랜드별 팀 / 하는 방식(기획·제작·디자인)별 팀 / 섞기
3. 자리 = 창 하나 (맡는 일 한 줄, 하지 않는 일 한 줄)
4. 창이 10개 넘으면 **총괄** 자리 두기 (일 나누기·쫓기·검수)
5. 여러 팀이 같이 쓰는 일은 **공통 자리**로 (광고·조사·개발)
6. **내가 직접 OK할 일** 정하기 (발행·결제·배포·고객에게 보내기)
7. **진행판** 하나 (아이디어 → 기획 → 원고 → 예약 → 발행)
8. 창끼리 말하는 곳 하나, 기록하는 곳 하나
9. 자리별 지침 세 줄 (맡은 일 / 하지 않는 것 / 보고 방식)
10. 조직도 한 장 그림으로

### 예시 (가상 회사)
```
대표(사람)
 └ 총괄 ── 일 나누기 · 검수 · 대표 차례 올리기
    ├ A브랜드팀: 기획 · 글 · 디자인 · 영상
    ├ B브랜드팀: 글 · 디자인
    └ 공통: 광고 · 조사 · 개발
```
