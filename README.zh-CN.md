# ai-org-chart · 为你的 AI 团队画组织架构图

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | **简体中文**

AI 窗口一旦超过十个,就说不清谁在做什么,最后你自己变成了组长,工作就停下来了。
把这些窗口**像小公司一样**分工:每个窗口只做自己的事,你只需要点头确认。

### 不用安装,直接试
把 [PROMPT.zh-CN.md](PROMPT.zh-CN.md) 里的文字粘贴到你常用的 AI(Claude、ChatGPT、Gemini)里。AI 会一次问你一个问题,最后画出组织架构图。

### 作为 Claude Code 技能使用
对 Claude 说:
> "把 github.com/gonipro/ai-org-chart 里的 skills/ai-org-chart 安装到我的技能目录(~/.claude/skills),然后帮我做 AI 组织架构图。"

### 10 个步骤
1. 写下每周重复的所有工作
2. 选择分组方式:按品牌/渠道、按工作类型(策划、制作、设计),或两者结合
3. 一个岗位 = 一个窗口(一行写负责什么,一行写不负责什么)
4. 窗口超过 10 个时,设一个**总协调**岗位(分配工作、跟进、审核)
5. 多个团队共用的工作放到**共享岗位**(广告、调研、开发)
6. 定好**只有你能批准**的事(发布、付款、上线部署、发给客户的消息)
7. 一个**进度看板**(想法 → 策划 → 草稿 → 排期 → 已发布)
8. 一个让窗口之间交流的地方,一个记录决定的地方
9. 每个岗位三行说明(负责什么 / 不负责什么 / 怎么汇报)
10. 把组织架构图画成一页

### 示例(虚构公司)
```
老板(人)
 └ 总协调 ── 分配工作 · 审核 · 把决定交给老板
    ├ 品牌 A 团队:策划 · 文案 · 设计 · 视频
    ├ 品牌 B 团队:文案 · 设计
    └ 共享:广告 · 调研 · 开发
```
