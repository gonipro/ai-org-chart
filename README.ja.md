# ai-org-chart · AIミニ会社の組織図をつくる

[English](README.md) | [한국어](README.ko.md) | **日本語** | [简体中文](README.zh-CN.md)

AIのウィンドウが10個を超えると、誰が何をしているのか分からなくなり、結局あなたがチームリーダー役をすることになって仕事が止まります。
ウィンドウを**小さな会社のように**分ければ、それぞれが自分の仕事だけをして、あなたはOKを出すだけです。

### インストールなしで試す
いつも使っているAI(Claude・ChatGPT・Gemini)に [PROMPT.ja.md](PROMPT.ja.md) の文章を貼り付けてください。AIが一つずつ質問し、組織図まで描いてくれます。

### Claude Code のスキルとして使う
Claudeにこう伝えてください。
> 「github.com/gonipro/ai-org-chart の skills/ai-org-chart を自分のスキル(~/.claude/skills)にインストールして、私のAI組織図を作って」

### 作り方(10ステップ)
1. 毎週くり返す仕事をすべて書き出す
2. 分け方を選ぶ:ブランド・チャネル別/仕事の種類(企画・制作・デザイン)別/両方
3. 1席 = 1ウィンドウ(担当を1行、やらないことを1行)
4. ウィンドウが10個を超えたら**統括**の席を置く(仕事の割り振り・進行管理・チェック)
5. 複数チームで使う仕事は**共通の席**へ(広告・調査・開発)
6. **自分だけがOKする仕事**を決める(公開・支払い・デプロイ・顧客への送信)
7. **進行ボード**を一つ(アイデア → 企画 → 原稿 → 予約 → 公開)
8. ウィンドウ同士が話す場所を一つ、記録する場所を一つ
9. 席ごとの指示を3行(担当/やらないこと/報告の仕方)
10. 組織図を1枚の図にする

### 例(架空の会社)
```
代表(人間)
 └ 統括 ── 仕事の割り振り · チェック · 代表への確認
    ├ ブランドAチーム:企画 · 文章 · デザイン · 動画
    ├ ブランドBチーム:文章 · デザイン
    └ 共通:広告 · 調査 · 開発
```
