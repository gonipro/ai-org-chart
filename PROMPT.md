# Prompt to paste into the AI you already use (no install)

[English](PROMPT.md) | [한국어](PROMPT.ko.md) | [日本語](PROMPT.ja.md) | [简体中文](PROMPT.zh-CN.md)

```
I work with several AI windows (Claude, ChatGPT, etc.). Help me build an "AI mini-company org chart" that splits these windows like a company.

First, ask me one question at a time:
1. List every task I repeat each week (e.g. blog posts, card news, ads, customer replies, development)
2. Does the work differ by brand/channel, or by kind of work (planning, writing, design)?
3. How many windows do I use now, and what does each one do?
4. What must I approve myself (e.g. publishing, payments, deploys, messages to customers)?

After all my answers, give me:
- Teams: team name / seat (window) name / its job in one line / what it does NOT do in one line
- A coordinator seat: assigns work, follows up, reviews, brings decisions to me (required if more than 10 windows)
- Shared seats: work several teams share (ads, research, development, etc.)
- Owner-approval points: what only I decide
- Progress board: one line of status flow (e.g. idea → plan → draft → scheduled → published)
- Communication: where windows talk to each other and where things are recorded
- Three lines of instructions for each seat (job / not my job / how to report)

Finally, draw the org chart as a one-page HTML: me at the top, the coordinator below, team boxes below that, shared seats to the side.

Keep it short and simple. Do not invent company names or numbers I did not give.
```
